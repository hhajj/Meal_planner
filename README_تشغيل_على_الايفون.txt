أكل اليوم — مخطط غذائي سنوي

محتويات الحزمة
- index.html: الصفحة الرئيسية التي يفتحها GitHub Pages.
- akl_esbou3_al_marathon.html: نسخة مستقلة لفتحها على الكمبيوتر.
- manifest.webmanifest و sw.js: إعدادات التثبيت والعمل دون اتصال وتحديث نسخة HTML عند الاتصال.
- apple-touch-icon.png و icon-192.png و icon-512.png: أيقونات التطبيق.

النشر على GitHub Pages
1. ارفعي جميع ملفات الحزمة إلى جذر المستودع نفسه، بحيث يكون index.html في المستوى الرئيسي وليس داخل مجلد فرعي.
2. افتحي Repository → Settings → Pages.
3. ضمن Build and deployment اختاري Deploy from a branch.
4. اختاري الفرع main والمجلد /(root)، ثم Save.
5. بعد اكتمال النشر، سيعرض GitHub رابط الموقع. شاركي رابط الموقع مع زوجتك، وليس رابط Code/Repository.
6. كل مرة تستبدلين فيها الملفات وتعملين Commit/Push إلى main، ينشر GitHub Pages النسخة الجديدة تلقائياً.

التثبيت على iPhone
1. افتحي رابط الموقع في Safari على iPhone.
2. اضغطي Share → Add to Home Screen.
3. فعّلي Open as Web App إن ظهر الخيار، ثم Add.
4. افتحي التطبيق من الأيقونة. بعد أول زيارة ناجحة، يمكن أن يعمل دون اتصال وفق إمكانات Safari.

تحديث التطبيق
- عند النشر، تبقى زوجتك على رابط الموقع نفسه؛ لا تحتاج إلى تثبيت أيقونة جديدة.
- صفحة HTML تستخدم استراتيجية Network-first: عند فتح التطبيق مع وجود الإنترنت، يجلب المتصفح الصفحة الأحدث ويحدّث النسخة المخزنة للعمل دون اتصال.
- إن بقيت نسخة قديمة بعد النشر، أغلقي التطبيق وافتحيه مجدداً مع الاتصال بالإنترنت، ثم حدّثي الصفحة. قد يستغرق انتشار نشر GitHub Pages بعض الوقت.
- لا تحذفي بيانات Safari أو بيانات الموقع عند التحديث؛ هذا قد يحذف سجل الوجبات المحفوظ محلياً.

البيانات والخصوصية
- الوزن، الوجبات، المخزن المنزلي والاختيارات تحفظ محلياً في متصفح/جهاز كل مستخدم عبر localStorage.
- هذه البيانات لا تتزامن تلقائياً بين هاتف الزوجة والكمبيوتر أو بين جهازين. استخدمي «حفظ نسخة» و«استرجاع» لنقل نسخة JSON يدوياً.
- الملفات المنشورة على GitHub Pages تكون متاحة عبر الإنترنت. لا تضعي معلومات شخصية أو أسراراً أو كلمات مرور داخل المستودع.

وظيفة «شو نطبخ اليوم؟»
- حدّدي المكونات الموجودة فعلياً في البيت من مجموعات البروتينات، الحبوب، الخضرة، أساسيات الطبخ والحلويات.
- يعرض التطبيق وصفات لبنانية ووجبات فطور وسناك وحلو من قاعدة الوجبات الحالية، مع أولوية للوصفات التي تكتمل مكوناتها في البيت.
- يمكن تفعيل خيار إظهار وصفات ينقصها مكوّن واحد فقط من الدكان القريب.
- ترتيب الاقتراحات يراعي ميزانية السعرات والماكروز لكل فترة من اليوم. عند اختيار وصفة، تُضاف إلى الفترة المناسبة مع كمية ابتدائية قابلة للتعديل.
- هذه اقتراحات محلية مبنية على قواعد وقائمة وصفات ثابتة، وليست بحثاً مباشراً على الإنترنت أو نظام ذكاء اصطناعي يولّد وصفات جديدة. راجعي المكونات والطريقة الفعلية قبل الطبخ.

تحضير الطعام
- حدّدي عدد الحصص في كل وجبة؛ «تحضير الطعام» يضرب كمية الحصة بالعدد ويعرض الإجمالي التقريبي.
- أوزان الأطباق المرجعية هي للأكل المطبوخ/الجاهز، وقد تختلف حسب الوصفة المنزلية والزيت والسمنة والمنتج.

حساب السعرات
- المعطيات الافتراضية: رجل، 42 سنة، 180 سم، 92 كغ. يمكن إدخال وزن مختلف لكل يوم.
- الاحتياج تقديري من معادلة Mifflin–St Jeor، معامل الحركة اليومية، وسعرات التمرين المحسوبة تقريبياً. لا تعاملي الناتج كقياس مباشر.
- لا تستخدم الأداة وحدها لتخطيط تغذية حالة مرضية أو بروتوكول سباق؛ عدّلي الأهداف وفق الاستجابة الفعلية والاختصاصي عند الحاجة.
